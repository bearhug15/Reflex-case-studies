# HandDryer

## Естественный язык

1) Тепловентилятор должен включиться за время, приемлемое с точки зрения пользователя (не позже 0.2 секунды), после того, как под ним появляются руки. 
2) Тепловентилятор никогда не включается произвольно (Если нет рук и тепловентилятор не включен, то он не включится до тех пор, пока не появятся руки). 
3) Если руки убрали, то не более чем через 1 с тепловентилятор выключится, если руки за это время не появились вновь. 
4) Если руки имеются и тепловентилятор включен, он не выключится. 
5) Время непрерывной работы тепловентилятора не более часа.

## FOL

1) R1_full s \<equiv>
toEnvP s \<and>
(\<forall> s1 s2.
  substate s1 s2 \<and>
  substate s2 s \<and> 
  toEnvP s1 \<and> 
  toEnvP s2 \<and>
  toEnvNum s1 s2 = 1 \<and>
  getVarBool s1 ''hands'' = False \<and>
  getVarBool s1 ''work'' = False \<and>
  getVarBool s2 ''hands'' = True \<longrightarrow>
    (\<exists>s4. 
      toEnvP s4 \<and> 
      substate s2 s4 \<and> 
      substate s4 s \<and>
      toEnvNum s2 s4 \<le> 1 \<and> 
      getVarBool s4 ''work'' = True \<and>
      (\<forall> s3. 
        toEnvP s3 \<and> 
        substate s2 s3 \<and>
        substate s3 s4 \<and> 
        s3 \<noteq> s4 \<longrightarrow>
          getVarBool s3 ''hands'' = True)))

2) R2_full s \<equiv> 
toEnvP s \<and>
(\<forall>s1 s2.  
  substate s1 s2 \<and>
  substate s2 s \<and> 
  toEnvP s1 \<and> 
  toEnvP s2 \<and>
  toEnvNum s1 s2 = 1 \<and> 
  getVarBool s1 ''out_1'' = False \<and>
  getVarBool s2 ''inp_1'' = False \<longrightarrow>
    getVarBool s2 ''out_1'' = False)

3) R3_full s \<equiv>
toEnvP s \<and>
(\<forall>s1 s2. toEnvP s1 \<and> toEnvP s2 \<and>
   substate s1 s2 \<and>substate s2 s \<and>
   toEnvNum s1 s2 = 1 \<and> 20 \<le> toEnvNum s2 s \<and>
   getVarBool s1 ''inp_1'' = True \<and> getVarBool s1 ''out_1'' = True \<and> 
   getVarBool s2 ''inp_1'' = False \<longrightarrow>
     (\<exists>s4. toEnvP s4 \<and>
        substate s2 s4 \<and> substate s4 s \<and>
        toEnvNum s2 s4 \<le> 20 \<and>
        (getVarBool s4 ''out_1'' = False \<or> getVarBool s4 ''inp_1'' = True) \<and>
        (\<forall>s3. toEnvP s3 \<and> substate s2 s3 \<and> substate s3 s4 \<and> s3 \<noteq> s4 \<longrightarrow>
           getVarBool s3 ''out_1'' = True \<and> getVarBool s3 ''inp_1'' = False)))

4) R4_full s \<equiv> toEnvP s \<and>
    (\<forall>s1 s2.
        substate s1 s2 \<and>
        substate s2 s \<and>
        toEnvP s1 \<and>
        toEnvP s2 \<and>
        toEnvNum s1 s2 = 1 \<and>
        getVarBool s1 ''out_1'' = True \<and>
        getVarBool s2 ''inp_1'' = True \<longrightarrow>
        getVarBool s2 ''out_1'' = True)

5) R5_full s \<equiv>
toEnvP s \<and>  
(\<forall> s1 s3. 
  substate s1 s3 \<and> 
  substate s3 s \<and>
  toEnvNum s1 s3*100 > 3600000 \<longrightarrow>
    (\<exists> s2. substate s1 s2 \<and> substate s2 s3 \<and>
      getVarBool s2 ''out_1'' = False))"


# BaggageCarusel

## Естественный язык

1. Если багажная лента выключена (engine = False), кнопка включения нажата (startButton = PRESSED), на ленте отсутствует тяжелый багаж и багаж не застрял, багажная лента включается (engine = True).
2. Если багажная лента включена (engine = True) и обнаружено застревание багажа (stuck = True) или слишком тяжелый багаж (weight = HIGH), то багажная лента выключается (engine = False).
3. Если багаж отсутствует (pSensor = NOT_DETECTED), то багажная лента выключится не позднее, чем через время IDLE_TIMEOUT, если за это время не появится багаж (pSensor = DETECTED).
4. Если багажная лента включена и багаж присутствует (pSensor = DETECTED), багажная лента не выключится по крайней мере в течение времени IDLE_TIMEOUT, пока багаж не застрянет (stuck = True), или пока не будет обнаружен слишком тяжелый багаж (weight = HIGH).
